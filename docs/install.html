Install

Get it running

Everything runs locally on your machine. Two scripts do the work: .\install.ps1 once, then .\quarry.ps1 whenever you want something.

01 / Requirements

What you need

  • Windows + PowerShell PowerShell 5.1 or later - it ships with Windows.
  • Python 3.10+ Tick Add python.exe to PATH when installing from python.org.
  • Nothing else No accounts, no cloud, no telemetry. Dependencies are installed by the setup script.

02 / Setup

One-time setup

Open PowerShell inside the project folder and run:

PowerShell
> .\install.ps1

It checks Python, installs the dependencies (httpx, beautifulsoup4, lxml) and makes sure config.json exists.

Add -Autostart to start the local server automatically when you log in:

.\install.ps1 -Autostart

03 / Configuration

config.json

Lives next to quarry.ps1:

{
  "downloadDir": "",
  "port": 8765,
  "workers": 8,
  "delay": 0.2,
  "maxImages": 0,
  "maxGalleries": 10,
  "proxy": ""
}
KeyMeaning
downloadDir Where files go. Empty = <you>\Downloads\Quarry. -Out and the extension settings override this.
port Local server port. Must match the extension setting.
workers Parallel file downloads.
delay Minimum pause between requests to the same site (seconds).
maxImages Cap files per gallery (0 = no cap).
maxGalleries Cap galleries crawled from a search/tag page.
proxy HTTP or SOCKS5 proxy URL, empty = none.

04 / First download

Try it

PowerShell
> .\quarry.ps1 "<any-page-url>"
  • The site is detected from the URL - no flags needed.
  • Add -DryRun to resolve everything and download nothing.
  • Add -Open to open the folder when it finishes.
  • .\download.ps1 is an alias of the same command.

All flags: Usage | docs/guides/usage.md

05 / Troubleshooting

When something goes wrong

SymptomFix
Python not found Install Python 3.10+, enable Add to PATH, re-run .\install.ps1.
HTTP 403 / "blocked" The site wants a logged-in session. Open the page in your browser and use the extension button - it forwards your browser cookies.
"no media found" Generic mode only sees what the page shows - see docs/guides/sites.md.
Red dot in the popup Server is not running - .\start.ps1. More: Extension.
