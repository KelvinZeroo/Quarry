Extension

The browser button

One extension folder loads in Chrome and Firefox. Open any page, press Download this page, watch the progress - the download keeps running even if you close the popup.

Download for Chrome Download for Firefox

01 / What it does

Why the button beats the CLI sometimes

  • Collects from the live page Including lazy-loaded images the raw HTML does not contain.
  • Forwards your cookies Age-gated and logged-in pages work, because it uses the session you already have in the browser.
  • Saves where you choose Folder comes from the extension settings (gear icon), otherwise the server default.
  • Shows progress The popup shows counts and a bar; the toolbar badge shows the file count while running.

02 / Start the server

The local server first

The extension talks to a small server on 127.0.0.1 - start it first:

PowerShell
> .\start.ps1 # logs visible; Ctrl+C stops it > .\start.ps1 -NewWindow # runs in its own window

The green dot in the popup means everything is connected. Want it at every logon? .\install.ps1 -Autostart

03 / Chrome / Edge

Install in Chrome or Edge

  1. Download quarry-chrome.zip (button above) and extract it - you get a quarry folder. Using the repo instead? The extension/ folder works the same way.
  2. Open chrome://extensions
  3. Turn on Developer mode - the switch in the top right corner
  4. Click Load unpacked
  5. Select the extracted quarry folder - the Quarry card appears
  6. Pin it: puzzle icon in the toolbar -> pin Quarry

Update later: extract the new zip, then press the refresh arrow on the Quarry card.

04 / Firefox

Install in Firefox

  1. Download quarry-firefox.zip (button above) and extract it - you get a quarry folder
  2. Open about:debugging#/runtime/this-firefox
  3. Click Load Temporary Add-on...
  4. Select quarry/manifest.json inside the extracted folder
  5. The Quarry icon appears in the toolbar

Firefox does not keep unsigned add-ons after a restart. Load it again from about:debugging, or use a Developer/ESR build with xpinstall.signatures.required=false for a permanent install.

05 / Settings

Extension settings

Right-click the extension icon -> Options (or Settings in the popup). Everything is stored in your browser only.

  • Download folder - where the browser button saves (empty = server default)
  • Server port - must match config.json
  • Max files per download - 0 = everything

06 / Troubleshooting

When the button does not work

SymptomFix
Red dot in the popup Server is not running -> .\start.ps1
"Server offline" in options Same as above, or wrong port in the settings
Nothing found on the page Generic mode only sees what the page shows - see docs/guides/sites.md
CLI gets HTTP 403, button works Expected - the button forwards your browser cookies; the CLI does not log in for you

Closing the popup does not stop the download - reopen it to see the progress.
