01 / How it works

How it works

1

Install

Run .\install.ps1. It checks Python, installs the dependencies and creates config.json.

2

Paste a URL

.\quarry.ps1 <url> detects the site by itself. No flags to remember - the folder, retries and skip-list are handled for you.

3

Or just click

Start the local server, load the extension, open any page and press Download this page. Your login cookies are forwarded, so gated pages work too.

02 / Features

Why it is pleasant to use

  • One universal command Gallery, search page or any site at all - same command, site detected automatically.
  • Clean, predictable files Short folders, files named 0001_..., corrected extensions and an info.txt with the source link. No (1) clutter in your downloads.
  • Run it twice, download nothing A manifest skips finished files and retries failed ones, so re-running is instant.
  • Polite by default Rate limiting, retries, content checks - small files and error pages never get saved as fake images.
  • Local and private The server binds to 127.0.0.1 only and rejects requests from other websites. Nothing leaves your machine.
  • Chrome + Firefox One extension folder loads in both browsers - media is collected from the live page, so lazy-loaded images are included.

03 / Sites

Works on

  • ImageFap
  • PornPics
  • EroMe
  • Rule34
  • any other page (best effort)

Known sites use purpose-built extractors that resolve full-size originals. Everything else falls back to a generic grabber that takes what the page shows - including media found by the extension in the live DOM. Details and limits: docs/guides/sites.md.

04 / Quick start

Get started

  1. Copy the project folder and open PowerShell inside it.
  2. Run .\install.ps1
  3. Run .\start.ps1 and load extension/ into your browser - or skip straight to .\quarry.ps1 <url>.
