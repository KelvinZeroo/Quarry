01 / Browser extension

The browser button

Extract a zip above - you get a quarry folder. The extension talks to a local server - start it first:

PowerShell
> .\start.ps1 # logs visible; Ctrl+C stops it > .\start.ps1 -NewWindow # runs in its own window

The green dot in the popup means everything is connected. At every logon: .\install.ps1 -Autostart

Chrome / Edge

  1. Open chrome://extensions
  2. Turn on Developer mode - the switch in the top right corner
  3. Click Load unpacked
  4. Select the extracted quarry folder - the Quarry card appears
  5. Pin it: puzzle icon in the toolbar -> pin Quarry

Update later: extract the new zip, then press the refresh arrow on the Quarry card.

Firefox

  1. Open about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on...
  3. Select quarry/manifest.json inside the extracted folder
  4. The Quarry icon appears in the toolbar

Firefox does not keep unsigned add-ons after a restart. Load it again from about:debugging, or use a Developer/ESR build with xpinstall.signatures.required=false for a permanent install.

Settings

Right-click the icon -> Options (or Settings in the popup):

  • Download folder - empty = server default
  • Server port - must match config.json
  • Max files per download - 0 = everything

02 / Command line

The one command

  • Windows + PowerShell 5.1 or later - it ships with Windows.
  • Python 3.10+ Tick Add python.exe to PATH when installing.
  • Nothing else No accounts, no cloud, no telemetry.
PowerShell
> .\install.ps1 # one-time setup > .\quarry.ps1 <any-page-url> # site detected automatically
  • .\download.ps1 is kept as an alias.
  • Add -DryRun to resolve without downloading, -Open to open the folder after.
  • All flags: Usage

03 / Troubleshooting

When something goes wrong

SymptomFix
Python not found Install Python 3.10+, enable Add to PATH, re-run .\install.ps1.
Red dot / "Server offline" Server is not running -> .\start.ps1. Also check the port in the extension settings.
HTTP 403 / "blocked" The site wants a logged-in session. Open the page in your browser and use the extension button - it forwards your browser cookies.
"no media found" Generic mode only sees what the page shows - see docs/guides/sites.md.
